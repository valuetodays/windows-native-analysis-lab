# Windows Native Lab Analysis Report Template v1.0

## 1. 定位

Analysis Report 是 Windows Native Lab 的实验分析记录体系。

目标：

记录：

    实验程序
        ↓
    运行行为
        ↓
    API调用
        ↓
    x64dbg观察
        ↓
    Windows内部机制理解

避免实验只留下代码，而没有知识沉淀。

# 3. 实验目标

说明：

本实验希望验证什么 Windows 行为。

例如：

    验证用户态程序如何申请虚拟内存。

    观察：

    VirtualAlloc调用过程

    以及内存区域变化。

# 4. 背景知识

说明：

实验涉及的 Windows 概念。

例如：

    Windows进程拥有独立虚拟地址空间。

    VirtualAlloc用于申请虚拟内存。

    底层最终进入Windows内核。
